I recently completed a hands-on network engineering project in Cisco Packet Tracer: a secure network design for a two-floor restaurant.

The environment supports wired and wireless POS terminals, kitchen/service-bar printers, management workstations, internal application/infrastructure servers, and simulated Internet connectivity.

I implemented:

• VLAN segmentation for POS, printers, management, wireless POS, servers, and network management
• 802.1Q trunking and Layer 3 inter-VLAN routing
• Centralized DHCP/DNS with DHCP relay
• Static and default routing
• NAT/PAT for Internet connectivity
• WPA2-protected wireless POS connectivity
• Extended ACLs for inter-VLAN security
• SSH management and VTY restrictions
• Port security with sticky MAC learning
• PortFast and BPDU Guard
• NTP and centralized Syslog
• End-to-end validation and structured troubleshooting

A major part of the project was not just configuring the network, but validating each layer and troubleshooting issues involving VLAN assignment, trunking, DHCP, ACLs, port security, and interface states.

I built this lab to strengthen my practical networking skills while preparing for the CCNA and network engineering opportunities.
